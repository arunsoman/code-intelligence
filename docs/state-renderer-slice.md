# State renderer slice

Apply after the seven earlier patches, ending with the ER renderer. S3 now has a discovered state renderer and optional state.v1 metadata. Initial/final annotations, guards, explicit forbidden paths and replay semantics survive compilation; parallel transitions have unique identities and duplicate states are omitted with gaps. Missing or stale evidence is excluded. All lifecycle semantics remain INFERENCE: citations are inspection references rather than independent proof of guards, forbidden paths or runtime idempotency. An absent transition means unknown, never forbidden.

The shared canvas uses rounded state cards, distinct initial/final borders, stopped forbidden arrows and dotted replay paths. Labels and the text alternative carry meanings independently of color. Adaptive ELK, source inspection and the captured hover preview remain available; older views fall back to the generic renderer. No timing, Petri-net or observed-runtime semantics are claimed. Activity diagrams are a separate subsequent slice.

Validation: compiler, renderer, identity, legacy fallback, real ELK geometry, existing plugin contracts/workflow/sequence/ER/preview suites, typecheck and production build. Browser interaction is not validated in this environment. Existing broad geometry thresholds remain unchanged.
