# Activity renderer slice

Apply after the eight previous patches, ending with the state renderer. S2 now has optional activity.v1 metadata and a discovered activity renderer. Existing process, decision, event, state and external shapes survive compilation. Lane assignments are preserved even when the plan selects flow layout; lane-aware geometry separates responsibility bands. Non-lane S2 charts can use adaptive ELK. Parallel indexed links have unique IDs and self links remain visible. Existing source inspection, captured hover preview and camera behavior use the shared canvas. Older views fall back safely.

Every activity role, lane, ordering and branch annotation is an INFERENCE. Links retain indexed relationship kind and display `flow?`; a calls relationship does not prove exclusive branches, timing or concurrency. Fan-out is never automatically drawn as a parallel fork. This slice introduces neither observed timing nor verified fork/join semantics. Unassigned steps are explicitly identified in the text alternative.

Validation includes evidence filtering, indexed endpoints, metadata, repeated links, self calls, lane geometry, legacy fallback, existing focused suites, typecheck and production build. Browser interaction remains unverified. Existing broad geometry suite thresholds remain unchanged.
